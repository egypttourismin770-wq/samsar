# سمسار — Samsar

واجهة سمسار العقارية مبنية كصفحة HTML واحدة باستخدام Vue عبر CDN، ومتصلة بمشروع Supabase المخصص لها.

## روابط المنصة

- الصفحة العامة: https://egypttourismin770-wq.github.io/samsar/
- بوابة مدير النظام (تتطلب حساب admin): https://egypttourismin770-wq.github.io/samsar/?admin=1
- بوابة الموظفين (تتطلب حساب staff): https://egypttourismin770-wq.github.io/samsar/?staff=1
- لوحة عمل عامة للمدير والموظف المعتمد: https://egypttourismin770-wq.github.io/samsar/?dashboard=1

الروابط الخاصة لا تتجاوز تسجيل الدخول أو دور الحساب. إعدادات المنصة، الرسوم، الاسترداد، وسائل الدفع، تعيين الأدوار والصلاحيات متاحة للمدير فقط.

## الربط الحالي

- التسجيل وتسجيل الدخول بالبريد وكلمة المرور من Supabase Auth؛ الحسابات العامة تبدأ بدور عميل فقط.
- بيانات العقارات المنشورة تُقرأ من قاعدة البيانات مع الصور والخدمات.
- إذا لم توجد إعلانات حقيقية، تظهر ستة إعلانات وصور توضيحية عليها شارة **عرض تجريبي**. الاستفسارات وطلبات المعاينة الحقيقية محظورة لهذه الإعلانات، وهي مستبعدة من مؤشرات التشغيل.
- المالك يحفظ الإعلان كمسودة ويرفع حتى 10 صور من جهازه إلى Storage bucket باسم `property-images` (10 MB كحد أعلى للصورة). رسوم إنشاء الإعلان المبدئية 50 جنيهًا.
- بعد حفظ المسودة، تظهر خطوة دفع يدوي وإرسال إيصال. إثبات الدفع محفوظ في bucket خاص باسم `payment-receipts`، والمدير وحده يراجع الإيصال. بعد اعتماد الدفع تنتقل المسودة إلى حالة **قيد مراجعة النشر**؛ لا ينشر الإعلان تلقائيًا.
- وسائل الدفع الحالية معطلة افتراضيًا. على المدير إدخال بيانات الاستلام الرسمية والتعليمات لكل وسيلة قبل تفعيلها؛ لا تُجرى أي عملية دفع تلقائية أو تحصيل حقيقي من خلال هذا الربط اليدوي.
- إعدادات الهوية والألوان ووصف المنصة وروابط فيسبوك والموقع وQR ورقم واتساب وسياسات الرسوم/الاسترداد تُحفظ مركزيًا في `platform_settings`.
- رقم واتساب العام للشركة هو `+201016476924`. زر واتساب يفتح محادثة للشركة برسالة مجهزة، ولا يرسل رسائل تلقائية إلى أصحاب العقارات.
- العميل لا يرى رقم هاتف المالك. الاستفسار عن إعلان حقيقي يُحفظ على حساب العميل، ثم يراجعه موظف، ثم يطلب رد المالك داخل حسابه، ثم يراجع الموظف الرد ويرسله إلى حساب العميل.
- صلاحيات الموظفين قابلة للتعيين بشكل منفصل: مراجعة الاستفسارات، متابعة المعاينات، استخدام مساعد الموظفين الذكي، الاطلاع على الإعلانات غير المنشورة، والمهام التشغيلية. قاعدة البيانات تتحقق من الصلاحيات؛ إخفاء الأزرار وحده ليس حاجز الأمان.
- بيانات التقييمات والمفضلة ما زالت محلية/تجريبية، ولا تُعد سجلات إنتاجية موثوقة.

## المساعد الذكي الخارجي

دالة Supabase Edge Function باسم `samsar-ai-chat` منشورة مع التحقق من JWT. تستخدم بيانات الإعلانات المنشورة فقط ولا تستعلم عن ملف المالك أو رقم هاتفه أو واتساب الخاص به. كما تميّز الإعلانات التجريبية ولا تعد العميل بتوافرها. المحادثات والردود الناجحة تُحفظ في `ai_conversations` و`ai_messages`، وتظهر محادثات العميل على حسابه.

**المساعد الخارجي غير جاهز للاستخدام حتى يختار المدير مزودًا متوافقًا مع Chat Completions ويضبط عنوان API واسم النموذج، ثم يضيف المفتاح السري باسم `SAMSAR_AI_API_KEY` في Supabase Dashboard → Edge Functions → Secrets.** لا تضع المفتاح في `index.html` أو GitHub. إعدادات الاتصال تبدأ معطّلة؛ وبدون المفتاح لن تُرسل طلبات مدفوعة إلى مزود AI.

## قاعدة البيانات والأمان

مشروع Supabase المستخدم: `mrzmjuwmehyhhqknuucq`.

كل الجداول الـ23 في مخطط `public` عليها RLS، وتوجد جداول إضافية لمسار الاستفسارات والصلاحيات وإثباتات الدفع. لا تضف أبدًا مفتاح `service_role` أو أي مفتاح سري إلى ملف الواجهة.

تنبيه للصيانة: قاعدة البيانات كانت موجودة قبل إضافة هذا المستودع، وسجل الترحيلات الأولية فيه غير مكتمل. كما أن بعض الترحيلات الأخيرة التي طُبقت مباشرةً على المشروع لم تُصدّر كلها إلى `supabase/migrations` حتى الآن؛ لا تعتبر المجلد وحده حاليًا نسخة كاملة لإعادة بناء قاعدة جديدة من الصفر.

## قبل التفعيل العام للمدفوعات والذكاء الاصطناعي

1. اختبر الدخول بدور المدير والموظف والمالك والعميل، وتأكد أن الرابط المباشر لا يسمح بدخول دور غير مناسب.
2. جرّب مسار الاستفسار من حساب عميل إلى مراجعة الموظف، ثم رد المالك، ثم الرد النهائي للعميل.
3. لا تفعّل وسيلة دفع إلا بعد مراجعة رقم الاستلام والتعليمات. جرّب إثباتًا اختباريًا ثم راجعه يدويًا.
4. اختبر محادثة AI بعد إضافة المفتاح السري الصحيح؛ إبقاء إعداد `enabled=false` آمن حتى يتم الإعداد.
5. أضف رابط فيسبوك الرسمي الحقيقي من إعدادات المدير؛ الحقل متروك فارغًا حتى لا يتم اختراع رابط.
6. راجع إعداد Supabase Auth لتأكيد `Site URL` و`Redirect URLs` على عنوان GitHub Pages.
