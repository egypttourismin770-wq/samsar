# سمسار — Samsar

واجهة سمسار مبنية كصفحة HTML واحدة باستخدام Vue عبر CDN، ومتصلة بقاعدة Supabase المخصصة للمشروع.

## الربط الحالي

- تسجيل الدخول وإنشاء حساب بالبريد وكلمة المرور من Supabase Auth.
- إنشاء الحساب العام يبدأ بدور **عميل** فقط.
- قائمة العقارات المنشورة تُقرأ من `public.properties` مع الصور والخدمات.
- إعلانات المالك تُحفظ كمسودات في قاعدة البيانات؛ لا يتم نشرها تلقائيًا.
- صور الإعلان تُرفع إلى Storage bucket باسم `property-images`، بحد أقصى 10 صور من الواجهة.
- طلبات المعاينة وحالاتها ومواعيد المالك البديلة تُحفظ في `public.viewing_requests`.
- مدير النظام يمكنه تعيين الدور `customer` أو `owner` أو `staff` من شاشة المستخدمين.

## قاعدة البيانات

المشروع المستخدم: `mrzmjuwmehyhhqknuucq`.

ملفات `supabase/migrations` الجديدة تطابق إصدارات الترحيلات التي طُبقت بالفعل على قاعدة المشروع. قاعدة البيانات كانت موجودة قبل إضافة هذه الملفات؛ المستودع الأصلي لم يحتوِ على سجل الترحيلات الأولية بالكامل، لذلك هذا المجلد وحده ليس حاليًا نسخة كاملة تعيد إنشاء قاعدة جديدة من الصفر.

كل الجداول الـ23 في مخطط `public` عليها RLS. لا تضف أبدًا مفتاح `service_role` أو أي مفتاح سري إلى ملف الواجهة. مفتاح `publishable` الموجود في الصفحة مخصص للاستخدام العام، ويعتمد الأمان على سياسات قاعدة البيانات.

## ما يزال تجريبيًا / غير مفعّل

- المساعد الذكي، تقييمات العقارات، والمفضلة ليست محفوظة في قاعدة البيانات بعد.
- التقارير المالية، شكل المنصة وبعض إعدادات لوحة التحكم لا تمثل معاملات حقيقية.
- لا توجد بوابة دفع متصلة، ووسائل الدفع المعروضة في قاعدة البيانات معطّلة.
- لا يتم تحصيل رسوم نشر أو اشتراك أو تنفيذ استرداد أموال.
- مستندات إثبات الهوية والملكية لا تُرفع إلى تخزين آمن في هذه المرحلة.

## رابط الموقع واللوحة

بعد تفعيل GitHub Pages من **Settings → Pages** واختيار **Deploy from a branch → main → /(root)**:

- الصفحة الرئيسية: https://egypttourismin770-wq.github.io/samsar/
- رابط فتح لوحة الإدارة بعد تسجيل الدخول: https://egypttourismin770-wq.github.io/samsar/?dashboard=1

رابط اللوحة لا يتجاوز تسجيل الدخول؛ يطلب مصادقة Supabase ويفتح لوحة الإدارة فقط لحساب مدير أو موظف معتمد.

## قبل النشر العام

1. تأكد من أن GitHub Pages مفعّل وأن حالة آخر نشر ناجحة.
2. اضبط عنوان GitHub Pages في إعدادات Supabase Auth ضمن **Site URL**، وأضفه إلى **Redirect URLs**.
3. اختبر تسجيل حساب جديد وتأكيد البريد والدخول والخروج على العنوان المنشور.
4. اختبر حساب عميل، ثم ارفع صلاحية حساب مالك من شاشة المدير، واختبر الإعلان والصور وطلب المعاينة.
5. راجع التحذير الأمني المتبقي؛ حماية كلمات المرور المسرّبة غير مفعّلة في إعداد المشروع الحالي.
